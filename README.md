# Portfólio

Site pessoal de Lucas Almeida, feito só com HTML e CSS, com visual preto e branco minimalista.

Site publicado:https://almeidalucas-s.github.io/portfolio/

## Páginas

- **Sobre Mim** (`index.html`): foto, nome, cargo e três seções (área profissional, graduação, cursos e certificações).
- **Certificados** (`galeria.html`): certificados em cards. Clique para abrir a imagem grande em outra aba.
- **Contato** (`contato.html`): e-mail, WhatsApp e Instagram.

## Como rodar

Não precisa instalar nada. Baixe o projeto e abra o `index.html` no navegador. No VS Code, a extensão Live Server atualiza a página sozinha a cada alteração.

## Como editar

- **Textos:** altere direto nos arquivos `.html`.
- **Novo certificado:** copie um bloco `<figure class="certificado">` em `galeria.html`, cole logo abaixo e troque a imagem e o texto.
- **Cores e tamanhos:** ficam nas variáveis do começo do `style.css`.
